# ART Forms

WordPress-плагин для логики форм и квизов: схема полей в админке, экспорт кода/промпта для дизайна (ChatGPT), приём ответов, письма себе и клиенту, редирект и лог доставок.

**Версия:** 1.1.32  
**Требования:** WordPress 6.0+, PHP 7.4+

**Официальный репозиторий:** https://github.com/artbashlykov/art-forms

**Больше материалов автора:** https://forge.artbashlykov.ru

## Возможности

- Конструктор блоков и полей (имя, email, телефон, согласие на ПДн и др.)
- Экспорт и импорт форм между сайтами (JSON)
- Действия после отправки: письмо себе, письмо клиенту, редирект с задержкой
- Экспорт HTML-скелета и промпта, проверщик кода
- CRM «Ответы»: заявки по форме, этапы, таблица/канбан (порядок карточек), фильтры, история в карточке, менеджеры, уведомления
- CSV-экспорт с CRM-полями, лог доставок
- Антиспам: honeypot и лимит частоты

## Установка

1. Скачайте `art-forms.zip` из [Releases](https://github.com/artbashlykov/art-forms/releases/latest).
2. Установите через **Плагины → Добавить новый → Загрузить плагин** (или распакуйте в `wp-content/plugins/art-forms`).
3. Активируйте плагин и откройте меню **ART Forms**.

Либо через **ART Master Install**, если плагин добавлен в каталог.
